# Analysis Output Artifacts

This directory stores tabular CSV files and visualization charts generated by `backend/scripts/build_research_artifacts.py`.

> [!WARNING]
> **Demo / Mock Data Notice**:
> Artifacts generated while `LLM_MODE=mock` are deterministic mock fixtures designed to test the artifact generation and chart rendering pipelines.
> 
> They do **not** represent live model evaluations. Re-run `backend/scripts/build_research_artifacts.py` after completing a live evaluation or experiment to generate live artifacts.
