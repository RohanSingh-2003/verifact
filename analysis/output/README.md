# Analysis Output Artifacts

This directory stores tabular CSV files and visualization charts generated by `backend/scripts/build_research_artifacts.py`.

---

## File Index

- **`condition_rows.csv`**: Detailed per-question metrics across experimental conditions.
- **`condition_summary.csv`**: Aggregated means, standard deviations, and error rates per condition.
- **`paired_comparisons.csv`**: Within-subject paired score differences between same-model and cross-model verifiers.
- **`classification_flips.csv`**: Frequency and direction of classification flips.
- **`threshold_sweep.csv`**: Sensitivity analysis sweeping thresholds $\theta \in [0.10, 0.90]$.
- **`chart1_condition_means.png`**: Condition mean score comparison chart.
- **`chart2_score_difference.png`**: Paired score difference distribution.
- **`chart3_flip_rate.png`**: Classification flip rate comparison.
- **`chart4_threshold_sweep.png`**: Precision, Recall, and F1 curves across threshold sweeps.
- **`experiment_config.json`**: Frozen configuration metadata for the artifact generation run.
