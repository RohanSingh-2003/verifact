# Analysis Output Artifacts

> **Tabular CSV Metrics and Visualizations Generated from the Baseline Research Run**

This directory stores tabular data files and high-resolution chart figures generated by the artifact builder script (`backend/scripts/build_research_artifacts.py`).

---

## Artifact Index & Descriptions

| Filename | Artifact Type | Description & Columns / Contents |
| :--- | :--- | :--- |
| **`condition_rows.csv`** | Tabular Data | Per-question records across all 4 experimental conditions ($A \to A, A \to B, B \to A, B \to B$). Includes question ID, candidate answer text, mutant statements, observed verifier votes, and calculated MetaQA score. |
| **`condition_summary.csv`** | Tabular Summary | Aggregated condition statistics: sample sizes ($N$), mean hallucination scores, standard deviations, 95% confidence intervals, and violation rates. |
| **`paired_comparisons.csv`** | Paired Analysis | Within-subject differences between same-model and cross-model verifiers: $(S_{A \to A} - S_{A \to B})$ and $(S_{B \to B} - S_{B \to A})$. |
| **`classification_flips.csv`** | Classification Stability | Rate and direction of binary classification label flips across threshold $\theta = 0.50$ when the verifier identity changes. |
| **`threshold_sweep.csv`** | Sensitivity Analysis | Precision, Recall, F1 score, Specificity, and accuracy evaluated across thresholds $\theta \in [0.10, 0.90]$ in 0.05 increments. |
| **`chart1_condition_means.png`** | Figure (Bar Chart) | Visual comparison of mean hallucination scores across the four experimental conditions. |
| **`chart2_score_difference.png`** | Figure (Histogram) | Distribution plot of paired score differences between same-model and cross-model verifier conditions. |
| **`chart3_flip_rate.png`** | Figure (Bar Chart) | Proportion of questions exhibiting classification outcome flips between conditions. |
| **`chart4_threshold_sweep.png`** | Figure (Line Chart) | Sensitivity curves plotting Precision, Recall, and F1 across classification thresholds. |
| **`experiment_config.json`** | Metadata Snapshot | Frozen configuration metadata and runtime parameters of the artifact generation process. |
