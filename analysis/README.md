# VeriFact Research Analysis & Output Archive

> **Preserved Tabular and Graphical Artifacts from Baseline Research Runs & Live Evaluation Export Guides**

This directory contains preserved research analysis artifacts from the historical 2×2 baseline study, alongside documentation for running offline dataset evaluations and exporting CSV metrics via VeriFact's live API.

---

## Directory Overview

- **`output/`**: An immutable archive containing tabular CSV files and visualization figures derived from the baseline mock research run (`58baff20-fb86-4f43-b20e-895a086ceb6b`). See [`analysis/output/README.md`](output/README.md) for individual file definitions.
- **Evaluation Export API**: For active benchmarking over the formal 550-question dataset (`hallucination_benchmark_frozen.json`), VeriFact provides a standalone evaluations API (`/api/evaluations/*`).

## Historical Research Artifacts in `analysis/output/`

The artifacts in [`analysis/output/`](output/) were generated by `backend/scripts/build_research_artifacts.py` to validate data pipeline integrity and chart rendering workflows:

### Tabular CSV Data
- **`condition_rows.csv`**: Detailed per-question metrics, answer texts, and hallucination scores across experimental conditions.
- **`condition_summary.csv`**: Aggregated means, standard deviations, confidence intervals, and error rates per condition.
- **`paired_comparisons.csv`**: Within-subject paired score differences between same-model and cross-model verifier conditions.
- **`classification_flips.csv`**: Frequency and direction of classification label changes between conditions.
- **`threshold_sweep.csv`**: Sensitivity analysis sweeping classification thresholds $\theta \in [0.10, 0.90]$.

### Visualization Charts
- **`chart1_condition_means.png`**: Bar chart comparing mean hallucination scores across conditions.
- **`chart2_score_difference.png`**: Distribution plot of paired score differences (same-model minus cross-model).
- **`chart3_flip_rate.png`**: Proportion of questions exhibiting classification outcome flips.
- **`chart4_threshold_sweep.png`**: Precision, Recall, and F1 curves across classification thresholds.

> [!WARNING]
> **Deterministic Mock Fixtures Notice**:
> Artifacts in `analysis/output/` were generated under `LLM_MODE=mock` using deterministic mock fixtures (`model-a`, `model-b`). They validate pipeline operation and chart generation logic, and must **never** be cited as empirical findings about live commercial LLMs.

## Live Evaluation API & Exporting Results

In the current VeriFact architecture, offline dataset evaluation runs are executed through the live backend API and exported directly as CSV:

### 1. Trigger an Evaluation Run
To execute a formal evaluation on the frozen 550-question benchmark:

```bash
curl -X POST http://127.0.0.1:8000/api/evaluations/run \
  -H "Content-Type: application/json" \
  -d '{
    "dataset": "hallucination_benchmark_frozen",
    "threshold": 0.5,
    "name": "Live Evaluation Run",
    "generator_model": "gemma4:26b",
    "verifier_model": "microsoft/phi-4-reasoning:free"
  }'
```

### 2. Export Evaluation Results to CSV
```bash
# Download CSV containing all evaluated question rows, labels, and scores:
curl -O http://127.0.0.1:8000/api/evaluations/{evaluation_id}/export
```

### 3. Web Dashboard Inspection
In the web interface (`/history`), evaluation records, confusion matrices, and question-level traces can be inspected and exported directly from the browser.
